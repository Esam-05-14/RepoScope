# Prompt R3 — Graph algorithms and digest

Implement adjacency, reverse BFS with visited set and one predecessor, Tarjan or Kosaraju SCCs (iterative or stack-tested), and `graphDigest` per `contracts/identity.md`.

Default edge policy: value and mixed. Type-only cycles must not appear in that default.

Tests: chain, diamond, disconnected node, duplicate imports, self-loop, three-node cycle, type-only cycle, unresolved target, malformed source. Compare sets, not layout.

Stop when algorithm tests pass, including truncation indicators.
