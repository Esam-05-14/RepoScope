# How to use these prompts

Paste exactly one wave prompt into a new Cursor agent that already has this repository open. Do not combine waves.

After the wave: fill `reports/rN-stop-gate.md` from `reports/templates/wave-report.md`. An independent pass should try to falsify the wave claims before starting the next prompt.

The commit-and-push prompt is separate and only runs when the user asks to publish a reviewed path list.
