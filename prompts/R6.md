# Prompt R6 — Optional P1 Git adapter and boundaries

Only start if P0 R1–R5 gates passed. If the five-day core is behind, skip this prompt.

Read commits with `execFile` + `git ls-tree` / `git cat-file`. No checkout, reset, fetch, filters, or shell strings. Resolver uses the commit's virtual filesystem, not today's worktree.

Acceptance: dirty worktree hashes unchanged after two commit scans; historical alias resolves in-commit; hand-authored fixture diff matches.

JSON-only boundary policy with named path groups and forbidden edges. Each violation cites the rule and observation.

If the worktree-mutation test fails, keep P0 snapshot compare and do not claim Git support.
